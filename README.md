## 2. Теория

### 2.1. Движение каретки

Каретка массой $m$ скатывается без начальной скорости по плоскости, наклонённой под углом $\alpha$ к горизонту. Вдоль плоскости действуют составляющая силы тяжести $mg\sin\alpha$ и сила сопротивления движению $F_{\text{сопр}}$ (трение качения, сопротивление воздуха, трение в оси колёс). Второй закон Ньютона:

$$
ma = mg\sin\alpha - F_{\text{сопр}}.
$$

Если приближённо считать $F_{\text{сопр}} = \mu mg\cos\alpha$, где $\mu$ — эффективный коэффициент сопротивления, то

$$
a = g\left(\sin\alpha - \mu\cos\alpha\right). \tag{1}
$$

При малом $\mu$ вторым слагаемым часто пренебрегают: $a \approx g\sin\alpha$. Именно это приближение используется в простейшей обработке.

### 2.2. Кинематика

Каретка проходит путь $s$ из состояния покоя за время $t$:

$$
s = \frac{at^2}{2}
\quad\Longrightarrow\quad
a = \frac{2s}{t^2}. \tag{2}
$$

Путь $s$ между двумя датчиками времени известен, время $t$ измеряется в каждой попытке. По формуле (2) для каждой попытки вычисляется ускорение.

### 2.3. Два способа найти $g$

**Способ А — по каждому углу отдельно.** Из (1) без трения:

$$
g_i = \frac{\langle a\rangle_i}{\sin\alpha_i}. \tag{3}
$$

Здесь $\langle a\rangle_i$ — среднее ускорение для угла $\alpha_i$. Если трение заметно, то

$$
g_i = g - \mu g\cot\alpha_i,
$$

поэтому оценки $g_i$ систематически зависят от угла: при малых углах они занижены сильнее. Это не случайная ошибка, и усреднение по углам её не убирает.

**Способ Б — МНК по всем углам.** Зависимость (1) линейна по $\sin\alpha$:

$$
a = g\sin\alpha + b, \qquad b = -\mu g. \tag{4}
$$

Если по оси абсцисс отложить $\sin\alpha$, а по оси ординат — $\langle a\rangle$, то **угловой коэффициент прямой равен $g$**, а свободный член $b$ связан с сопротивлением движению. Это основной способ получения результата в данной работе: он использует все углы сразу и не требует пренебрегать трением при вычислении $g$.

### 2.4. Погрешности

- Случайная погрешность среднего ускорения для серии из $n$ попыток:

$$
\sigma_{\langle a\rangle} = \frac{1}{\sqrt{n}}\sqrt{\frac{1}{n-1}\sum_{j=1}^{n}\left(a_j-\langle a\rangle\right)^2}. \tag{5}
$$

- Погрешность $g_i$ из формулы (3): $\sigma_{g_i} = \sigma_{\langle a\rangle_i}/\sin\alpha_i$.
- Погрешность наклона прямой при МНК:

$$
\sigma_g = \sqrt{\frac{\sum_j r_j^2/(N-2)}{\sum_j\left(\sin\alpha_j-\overline{\sin\alpha}\right)^2}}, \tag{6}
$$

где $r_j$ — невязки прямой, $N$ — число углов (то есть число точек на графике, а не число отдельных измерений).

## 3. Установка и методика эксперимента

Эксперимент выполнен на учебной наклонной плоскости (длина около 1.2 м) с кареткой на колёсах. Время регистрировалось автоматически двумя фотодатчиками, поэтому журнал содержит очень много измерений.

**Оборудование:**

| Прибор | Характеристики |
|---|---|
| Наклонная плоскость с регулируемым углом | цена деления угломера 0.1° |
| Каретка на колёсах | масса $m = 0.487$ кг |
| Два датчика времени (фотодатчика) | дискретность 0.001 с |
| Линейка | цена деления 1 мм |
| Упор для пуска | каретка отпускается без начальной скорости |

**Методика:**

1. Плоскость выставляется под нужным углом; угол контролируется цифровым угломером.
2. На плоскости отмечаются стартовый и финишный датчики. Расстояние между ними $s = 0.800$ м (измерено линейкой).
3. Каретка устанавливается у верхнего упора и отпускается. Время прохождения базы $s$ фиксируется электронным секундомером, включённым по первому и выключенным по второму датчику.
4. Для каждого угла выполнено по **1000 проходов**. Результаты автоматически записывались в журнал; оператор не редактировал таблицу вручную.
5. Выполнены серии для семи углов: **8°, 10°, 12°, 15°, 18°, 22°, 26°**.
6. Всего в журнале **7000 строк**. Температура в лаборатории 21 ± 1 °C.

**Что важно понимать:** разброс времени между попытками при одном и том же угле — это случайная погрешность (неидеальный пуск, микроколебания, небольшие различия в положении каретки). Он виден по столбцу `time_s`. Систематические эффекты (трение, неточность установки угла, погрешность расстояния) по разбросу не видны и обсуждаются отдельно.

### 3.1. Качество данных

Журнал выгружен без предварительной очистки. В нём встречаются:

- **пропуски** — пустые ячейки в `time_s`, `distance_m`, `angle_deg` (датчик не сработал, оператор не заполнил поле);
- **полные дубликаты строк** — одна и та же попытка попала в журнал дважды;
- **грубые выбросы времени** — преждевременный или поздний останов секундомера: время в несколько раз меньше или заметно больше типичного;
- **физически невозможные значения** — отрицательное или нулевое время, путь 80 м (путь записан в сантиметрах вместо метров).

Если сразу вызвать `mean()` по «сырой» таблице, результат будет неверным: `NaN` «отравит» среднее, дубликаты исказят вес попыток, а один грубый выброс может сдвинуть среднее сильнее, чем сотни нормальных измерений. Поэтому перед расчётами нужно:

1. посмотреть на размер таблицы, типы колонок, число пропусков, дубликатов и диапазоны значений;
2. привести данные к числовому виду;
3. удалить (или обоснованно заполнить) пропуски;
4. удалить полные дубликаты;
5. отбросить физически невозможные значения;
6. найти грубые выбросы **отдельно для каждого угла** и удалить их по формальному критерию;
7. записать, сколько строк и по какой причине удалено.

Конкретные пороги и критерий выбросов вы выбираете сами, но они должны быть одинаковыми для всех серий и обоснованы в отчёте. Нельзя удалять точки только потому, что они мешают получить «красивое» $g$.

Подробное описание файла данных — в [`data/README.md`](data/README.md).
