# Паспорт данных

## Файл

`measurements.csv` — журнал измерений, выгруженный автоматически в одну таблицу.
Кодировка UTF-8, разделитель — запятая, десятичная точка.

| Колонка | Тип | Единицы | Описание |
|---|---|---|---|
| `angle_deg` | float | градусы | угол наклона плоскости к горизонту |
| `trial` | int | — | номер попытки внутри серии (1…1000) |
| `distance_m` | float | метры | путь каретки между датчиками |
| `time_s` | float | секунды | время прохождения пути |

Всего **7000 строк**: 7 углов (8°, 10°, 12°, 15°, 18°, 22°, 26°) по 1000 строк в каждой серии.

## Условия эксперимента

- Учебная наклонная плоскость, длина рабочей части ≈ 1.2 м.
- Каретка на колёсах, масса 0.487 кг.
- Путь между датчиками: 0.800 м (измерен линейкой, ±1 мм).
- Угол выставлялся по цифровому угломеру с ценой деления 0.1°.
- Время — по электронному секундомеру с дискретностью 0.001 с; пуск и останов
  срабатывают от фотодатчиков.
- Каретка отпускается из состояния покоя, без толчка.
- Температура воздуха 21 ± 1 °C.

## Качество данных

Журнал выгружен **без предварительной очистки**. В нём есть:

- пустые ячейки (пропуски) в `time_s`, `distance_m`, `angle_deg`;
- полные дубликаты строк — одна и та же попытка записана дважды;
- грубые выбросы времени — преждевременный или поздний останов;
- физически невозможные значения: отрицательное или нулевое время,
  путь 80 м (ошибка единиц: сантиметры вместо метров).

Конкретное число дефектных строк в паспорте не приводится: его нужно получить
самостоятельно при аудите данных и указать в отчёте. Все дефекты — часть
учебной задачи, а не повод выбросить файл.

## Что означают повторы

Каждая серия (один угол) содержит 1000 проходов. Различия во времени внутри
серии связаны с неидеальностью пуска, небольшими вариациями трения и
погрешностью срабатывания датчиков. По этим повторам оценивается случайная
погрешность среднего.

Систематические эффекты (трение, погрешность расстояния и угла) по повторам
не видны. О них нужно рассуждать отдельно — см. контрольные вопросы в
[`../README.md`](../README.md).

## Чего в файле нет

- Нет «идеальных» значений ускорения и $g$ — их нужно получить расчётом.
- Нет пометок «брак» у плохих строк: критерий качества нужно сформулировать
  самостоятельно.
- Нет данных других серий и калибровок.
